# Blowhard 0.2.0

This portfolio milestone adds an inspectable, end-to-end meeting-note workflow on top of the Kotlin Multiplatform
desktop foundation. It is designed to demonstrate architecture, AI boundary design, measurable evaluation, explicit
consent, and crash-safe persistence rather than claim broad product completeness.

## Highlights

- Bounded PDF, PNG, and JPEG import into app-owned storage with explicit OCR and image-question actions.
- Structured meeting-note generation with typed summary, decisions, action items, risks, and source references.
- Editable shared Compose presentation backed by durable revisions.
- Versioned synthetic evaluation dataset with deterministic JSON and Markdown reports.
- Optional live evaluation with explicit model selection, secure credential lookup, and hard case/time/token limits.
- Provider-neutral tool protocol, finite orchestration state machine, and hardened Mistral request mapping.
- Read-only `search_text` and `read_page` tools scoped to attached local documents.
- Exact, expiring, single-use approval for local note writes.
- Atomic note-and-receipt persistence with deterministic recovery and no automatic mutation replay.
- A five-minute reviewer path, architecture diagram, security posture, and feature-to-test evidence map.

## Verification evidence

The repository quality gate covers formatting, static analysis, tests, coverage, module boundaries, binary API
compatibility, KDoc, SQL migrations, dependency licenses, and secret scanning. Pull-request CI additionally compiles
Android and Apple shared targets and builds, installs, launches, and inspects native packages on Linux, Windows, and
macOS.

The checked-in fixture report is reproducible offline. It uses synthetic data and separates schema validity, field
quality, citation resolution, and semantic support. No live-model score is claimed unless a report explicitly records
the model identifier and run parameters.

A one-case [bounded live reference report](../evaluation/meeting-note-live-reference-2026-11-12.md) was generated on
2026-11-12 with `mistral-small-latest`. The response passed schema, source-resolution, and expected-outcome checks but
failed the stricter field-correctness and missing-field checks. It has not received semantic human review, token usage
was unavailable from the structured-output adapter, and the snapshot is evidence of the evaluation path rather than a
quality claim.

## Current limitations

- Packages lack trusted publisher signatures; macOS is not notarized.
- Secure live-provider configuration is implemented only for macOS.
- Android and iOS remain compilation-tested shared targets rather than released applications.
- Local application data is not independently encrypted at rest.
- The narrow tool protocol reads attached documents and writes an approved local note; it is not a general coding
  agent or arbitrary command runner.
- Model quality varies by model and input. The synthetic evaluation is reproducibility evidence, not a guarantee of
  correctness.
