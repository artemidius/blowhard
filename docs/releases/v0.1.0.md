# Blowhard 0.1.0

This foundation preview demonstrates a production-minded Kotlin Multiplatform architecture across
macOS, Windows, Linux, Android, and iOS compilation targets. The native desktop packages are the
first installable portfolio milestone.

## Highlights

- One shared Compose conversation workflow with deterministic offline scenarios.
- Explicit Mistral model discovery and streaming on the macOS reference host.
- Keychain-backed credential lifecycle with no secret in observable presentation state.
- Provider-neutral generation controls, immutable attempt provenance, and explicit regeneration.
- SQLDelight conversation persistence, fail-closed restart recovery, confirmed local deletion, and
  bounded run checkpoints.
- Content-free run inspection and explicit sanitized diagnostic export.
- Native `.dmg`, `.msi`, and `.deb` packages with install-and-launch CI evidence.

## Verification evidence

Every package is bound to the exact source revision by a deterministic manifest and SHA-256
checksum. Host-specific third-party dependency and license inventories accompany each package. The
release workflow rebuilds the selected `main` commit, reruns the complete quality gate, installs and
launches all three native packages, and places the result in a manually reviewed draft release.

## Current limitations

- Packages are not signed by a trusted publisher. The macOS package is ad hoc signed and not
  notarized; Windows and Linux packages are unsigned.
- Live Mistral configuration is supported only on macOS. Windows and Linux remain offline-demo-only
  until secure credential adapters are implemented.
- Automated provider tests use synthetic fixtures. No live-provider reliability or model-quality
  benchmark is claimed by this release.
- Android and iOS remain compilation-tested shared targets rather than distributed applications.
