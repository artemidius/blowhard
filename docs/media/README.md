# Application captures

Captured on 13 November 2026 from the running macOS desktop application and Android application on
an emulator. Both connected to Mistral with `mistral-small-latest`; the prompts and responses shown
are real. The examples contain only synthetic, public sample content.

| Asset | Content |
| --- | --- |
| `blowhard-showcase.png` | Framed desktop and Android screenshots on a branded presentation canvas |
| `desktop-chat.png` | Completed Kotlin code-generation conversation |
| `android-chat.png` | Completed mobile planning conversation |
| `desktop-chat.gif` | Desktop request and response excerpt, 1100 px wide |
| `android-chat.gif` | Android request and response excerpt, 432 px wide |

The standalone PNGs preserve the app pixels apart from cropping operating-system chrome and color
conversion. The cover scales and frames those captures. GIFs use successive screen captures with
a reduced frame rate and palette; they illustrate interaction and are not latency benchmarks.
Responses, controls, and connection state have not been composited or rewritten.

Capture credentials are excluded from all assets. PNGs contain no EXIF or XMP metadata. Only the
finished media is tracked; temporary credentials, app data, and capture instrumentation are not.
